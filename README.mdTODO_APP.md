# WhatsApp-Bot 🤖

WhatsApp Bot with Antilink, Auto React, Welcome, and Song features

## ✨ Features
- **Antilink**: Group me koi link bheje to auto delete
- **Auto React**: Har message par auto reaction
- **Welcome**: Naya member aaye to welcome message
- **Song**: `!song atif aslam` likho gana mil jayega

## ⚡ Kaise Chalayen
```bash
git clone https://github.com/Syedwaqar786/WhatsApp-Bot
cd WhatsApp-Bot
npm install
npm start
